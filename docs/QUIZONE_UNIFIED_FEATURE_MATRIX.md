# QuiZone AI — unified feature matrix (module level)

Feature-level detail is in `QUIZONE_FEATURE_MATRIX.md`. **VERIFIED** = browser E2E on a real Supabase stack plus DB tests. **DB-VERIFIED** = DB/unit tests only. **PARTIAL** = some of the requested scope is missing. **NOT IMPL** = absent. **BLOCKED** = needs a decision or access.

| Module                         | Status               | What works                                                                                                                                      | What's missing (blocker)                                                          |
| ------------------------------ | -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| **QuizZone** (QuickZone)       | VERIFIED, PARTIAL    | Discovery, lobby, questions, server scoring with speed/streak bonuses, explanations, results, replay, Parent Hub reporting, XP                  | Subject/difficulty filters, adaptive questions, AI generation (provider)          |
| **BuildZone**                  | DB-VERIFIED          | Costed blueprint (server budget check), pitch steps, saved design, XP                                                                           | Browser journey; portfolio; free-text pitch (`FAMILY.md` review); educator review |
| **DebateZone**                 | DB-VERIFIED          | Assigned position, six fixed stages, evidence/rebuttal choices, history                                                                         | Browser journey; AI feedback (provider)                                           |
| **SafeZone**                   | VERIFIED (flag off)  | Full town hall lifecycle, consent, cards, polls, safeguarding, Parent Hub, export                                                               | Hosted UAT; legal/moderator gates; AI facilitator; impact tracker                 |
| **Family Game Night**          | VERIFIED, PARTIAL    | Create game, lobby/ready/active, shared-screen play, shared score, history, play again, scheduling                                              | Invitations, multi-device sync, family achievements model (QZ-05)                 |
| **Global Connect** (WorldZone) | DB-VERIFIED, PARTIAL | Guardian-gated country challenge, private passport stamps                                                                                       | Moderated cross-household submissions (`FAMILY.md` §3: aggregate only)            |
| **AI Learning Companion** (Q)  | DB-VERIFIED, PARTIAL | Curated hints, permission-gated, capped, logged                                                                                                 | Live model: **BLOCKED** (provider and key)                                        |
| **Guardian Hub**               | VERIFIED             | Household, explorers (edit/archive/delete), permissions, Parent Hub (games, hints, reports, SafeZone), export, password, sign-out-all, deletion | Notifications beyond SafeZone; consent version history                            |
| **Educator Hub**               | NOT IMPL             | —                                                                                                                                               | **Decision:** PRD lists Teacher as post-MVP                                       |
| **Platform Admin**             | PARTIAL              | Challenge draft → age review → publish; game moderation queue; SafeZone console and safeguarding queue; audit trail                             | Role/flag management UI (SQL-only by design for now); monitoring dashboard        |
