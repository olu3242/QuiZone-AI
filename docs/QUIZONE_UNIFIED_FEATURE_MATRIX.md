# QuiZone AI — unified feature matrix (module level)

Feature-level detail is in `QUIZONE_FEATURE_MATRIX.md`. **VERIFIED** = browser E2E on a real Supabase stack plus DB tests. **DB-VERIFIED** = DB/unit tests only. **PARTIAL** = some of the requested scope is missing. **NOT IMPL** = absent. **BLOCKED** = needs a decision or access.

| Module                         | Status              | What works                                                                                                                                                                                                                          | What's missing (blocker)                                               |
| ------------------------------ | ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| **QuizZone** (QuickZone)       | VERIFIED, PARTIAL   | Discovery with subject/difficulty filters, server scoring with speed/streak, explanations, practice rounds, replay, CMS-authored multi-step quizzes behind a quality gate, levels and badges                                        | Adaptive questions and AI generation (provider)                        |
| **BuildZone**                  | VERIFIED, PARTIAL   | Costed blueprint (client and server budget check), pitch steps, saved design, XP, kill switch                                                                                                                                       | Portfolio; free-text pitch (`FAMILY.md` review); educator review       |
| **DebateZone**                 | VERIFIED, PARTIAL   | Assigned position, six fixed stages (no free text), evidence/rebuttal choices, history, kill switch                                                                                                                                 | AI feedback (provider)                                                 |
| **SafeZone**                   | VERIFIED (flag off) | Full town hall lifecycle, consent, cards, polls, safeguarding, Parent Hub, export                                                                                                                                                   | Hosted UAT; legal/moderator gates; AI facilitator; impact tracker      |
| **Family Game Night**          | VERIFIED            | Create game, lobby/ready/active, shared-screen play, shared score, history, play again, scheduling; guardian-invited adults play on their own devices with lobby presence (QZ-31) | Family achievements beyond the 3 family badges |
| **Global Connect** (WorldZone) | VERIFIED            | Guardian-gated country challenge, household-private passport stamps, kill switch; aggregate cross-household answer distributions (k ≥ 5, no identities, QZ-33) | Free-text cross-household submissions (out by `FAMILY.md` §2); international privacy review |
| **AI Learning Companion** (Q)  | VERIFIED, PARTIAL   | Curated hints: guardian-gated, capped, logged in Parent Hub, operator kill switch. Claude adapter suggests hints to CMS authors (flag `q_live`, off; screened, audited, rate-limited, QZ-34) | Live child-facing generation: needs a trusted server-side writer + safeguarding review |
| **Guardian Hub**               | VERIFIED            | Household, explorers, permissions, daily Q hint limit, versioned consent, Parent Hub, export, password, sign-out-all, deletion; family-member invites and removal; Explorer mode lock for the shared screen (QZ-31–32) | Notifications beyond SafeZone |
| **Educator Hub**               | NOT IMPL (non-goal) | —                                                                                                                                                                                                                                   | PRD §2: Teacher is post-MVP |
| **Platform Admin**             | VERIFIED, PARTIAL   | Multi-step CMS (draft, version, retire) with an enforced quality gate; game moderation queue; SafeZone console; operations overview (aggregates); per-zone kill switches; audit trail                                               | Role/flag management UI (SQL-only by design)                           |
